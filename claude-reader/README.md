# خوانا — Claude Reader

افزونه‌ی کروم برای راحت‌تر خواندن و درس‌خواندن با پاسخ‌های [claude.ai](https://claude.ai).

## نصب (حالت توسعه‌دهنده)

1. این مخزن را دانلود یا clone کن.
2. در کروم برو به `chrome://extensions` و **Developer mode** را روشن کن.
3. **Load unpacked** را بزن و پوشه‌ی `claude-reader/extension` را انتخاب کن.
4. یک گفتگو در claude.ai باز کن (اگر از قبل باز بود، صفحه را یک بار رفرش کن).

## قابلیت‌ها

| قابلیت | چطور |
| --- | --- |
| **فونت** | فونت فارسی (وزیرمتن، استعداد، ساحل، صمیم، شبنم، نسخ، Tahoma یا هر فونت نصب‌شده) و فونت انگلیسی جدا از هم؛ اندازه، فاصله‌ی خطوط، ضخامت، فاصله‌ی کلمات و پاراگراف، عرض ستون متن. از منوی افزونه ← «فونت». |
| **تم و رنگ** | ۹ تم آماده (کاغذی، سپیا، نعنایی، شب، کهربایی، نورد، مشکی کامل، …) + تم سفارشی با انتخاب رنگ. حالت روشن/تیره‌ی خود Claude هم هماهنگ می‌شود. |
| **هایلایت رنگی** | متن را انتخاب کن ← یکی از ۶ رنگ. روی هایلایت کلیک کنی رنگش عوض یا حذف می‌شود. «حالت ماژیک» در نوار کناری: هر متنی انتخاب کنی فوراً هایلایت می‌شود. |
| **یادداشت** | روی متن انتخاب‌شده یادداشت بگذار (دکمه‌ی یادداشت یا `Alt+N`). یک «دفترچه» هم برای هر گفتگو هست. |
| **راست‌چین اصولی** | هر پاراگراف، لیست، جدول و تیتر جدا بررسی می‌شود: فارسی راست‌چین، انگلیسی چپ‌چین، کد و فرمول همیشه چپ‌چین. بولت‌ها و فاصله‌ها هم قرینه می‌شوند. سه حالت: خاموش / خودکار / همیشه. جعبه‌ی تایپ پیام هم خودکار راست‌چین می‌شود. |
| **خط جداکننده** | دکمه‌ی خط در نوار کناری ← بالا یا پایین هر پاراگراف کلیک کن. ۵ سبک، رنگ و عنوان اختیاری روی خط. |
| **مداد** | مداد، ماژیک شفاف، خط صاف (خودش افقی می‌چسبد) و پاک‌کن؛ با رنگ و ضخامت دلخواه. `Ctrl+Z` برای برگشت. |
| **قالب‌بندی متن** | بولد، ایتالیک، زیرخط، خط‌خورده، رنگ متن، قالب کد، کادر، نقل‌قول (کوت) و کادر «مهم» برای پاراگراف. |
| **پنل یادداشت‌ها** | فهرست همه‌ی هایلایت‌ها و یادداشت‌های گفتگو با فیلتر رنگ؛ کلیک = پرش به همان قسمت. خروجی Markdown. |
| **کتابخانه** | صفحه‌ی جدا با همه‌ی گفتگوها، جستجو، خروجی Markdown و پشتیبان‌گیری/بازگردانی JSON. |
| **پنهان‌کردن** | دکمه‌ی چشم: یک لحظه همه‌ی علامت‌ها را پنهان کن تا متن اصلی را ببینی. |

## حافظه (بعد از برگشتن چیزی پاک نمی‌شود)

همه‌چیز برای **هر گفتگو جداگانه** با شناسه‌ی آدرس آن (`claude.ai/chat/…`) در حافظه‌ی خود کروم (`chrome.storage.local`) ذخیره می‌شود. وقتی به آن گفتگو برگردی — با رفرش، بستن و بازکردن مرورگر، یا رفتن به گفتگوی دیگر و برگشتن — هایلایت‌ها، یادداشت‌ها، خط‌ها و طراحی‌ها دوباره سر جایشان می‌آیند. تنظیمات (فونت، تم، …) در `chrome.storage.sync` است و با حساب کروم بین دستگاه‌ها همگام می‌شود.
هیچ داده‌ای به هیچ سروری فرستاده نمی‌شود. برای اطمینان، از کتابخانه گاهی «پشتیبان‌گیری (JSON)» بگیر.

## میان‌برها

| کلید | کار |
| --- | --- |
| `Alt+1` … `Alt+6` | هایلایت با رنگ‌ها (روی متن انتخاب‌شده) |
| `Alt+B` / `I` / `U` / `S` | بولد / ایتالیک / زیرخط / خط‌خورده |
| `Alt+Q` | نقل‌قول |
| `Alt+N` | یادداشت |
| `Alt+0` | حذف قالب‌ها از متن انتخاب‌شده |
| `Alt+P` | مداد |
| `Alt+L` | خط جداکننده |
| `Alt+H` | حالت ماژیک |
| `Alt+M` | پنل یادداشت‌ها |
| `Alt+R` | حالت راست‌چین |
| `Esc` | خروج از ابزار |

کلیدها با کیبورد فارسی هم کار می‌کنند.

## محدودیت‌های فعلی

- طراحی‌های مداد به پیام چسبیده‌اند و با آن اسکرول می‌شوند، ولی اگر بعداً فونت یا اندازه‌ی متن را عوض کنی، ممکن است کمی نسبت به متن جابه‌جا شوند.
- اگر پاسخی را دوباره تولید (Retry) یا ویرایش کنی و متن عوض شود، هایلایت‌های آن قسمت در پنل با برچسب «در صفحه پیدا نشد» می‌مانند (پاک نمی‌شوند).
- اگر Claude ساختار صفحه‌اش را عوض کند، ممکن است لازم باشد انتخابگرهای `extension/src/content/dom.js` (بخش `SEL`) به‌روز شوند.

## ساختار پروژه

```
extension/              ← همین پوشه را در کروم Load unpacked کن
  manifest.json
  fonts/                ← فونت‌ها (همه OFL)
  src/shared/           ← تنظیمات پیش‌فرض، تم‌ها، ذخیره‌سازی، خروجی Markdown
  src/content/          ← کدی که داخل claude.ai اجرا می‌شود
    dom.js              ← پیدا کردن پیام‌ها و لنگر متن (برای برگرداندن هایلایت‌ها)
    appearance.js       ← فونت، تم، راست‌چین
    annotations.js      ← هایلایت، قالب، یادداشت، نقل‌قول، خط جداکننده
    drawing.js          ← مداد
    ui.js / ui.css      ← نوار کناری، نوار انتخاب، پنل
    main.js             ← راه‌اندازی، دنبال‌کردن تغییرات صفحه، میان‌برها
  src/popup/            ← منوی تنظیمات افزونه
  src/library/          ← کتابخانه‌ی یادداشت‌ها
dev/                    ← تست خودکار و ساخت آیکون (لازم برای استفاده نیست)
```

## تست خودکار

```bash
cd dev
npm install
CHROMIUM_PATH=/path/to/chrome npm test
```

تست، افزونه را در کرومیوم باز می‌کند، یک صفحه‌ی شبیه‌سازی‌شده‌ی claude.ai (با React) را جای سایت اصلی می‌گذارد و همه‌ی قابلیت‌ها را امتحان می‌کند؛ عکس‌ها در `dev/out/` ذخیره می‌شوند.
