# خوانا — Claude Reader

افزونه‌ی کروم برای راحت‌تر خواندن و درس‌خواندن با پاسخ‌های [claude.ai](https://claude.ai) و چت Notion AI.

## نصب (حالت توسعه‌دهنده)

1. این مخزن را دانلود یا clone کن.
2. در کروم برو به `chrome://extensions` و **Developer mode** را روشن کن.
3. **Load unpacked** را بزن و پوشه‌ی `claude-reader/extension` را انتخاب کن.
4. یک گفتگو در claude.ai یا چت Notion AI باز کن (اگر از قبل باز بود، صفحه را یک بار رفرش کن).

### خواندن با صدا چطور کار می‌کند؟

از موتور گفتار خود مرورگر (Web Speech API) استفاده می‌کند: **کاملاً رایگان، بدون کلید و بدون سرور**. کیفیت و زبان‌ها به صداهای نصب‌شده روی سیستم بستگی دارد:

- **انگلیسی** تقریباً همه‌جا صدای خوب دارد.
- **فارسی**: کروم روی ویندوز/مک معمولاً صدای فارسی ندارد. در این حالت افزونه بخش‌های فارسی را رد می‌کند و خبر می‌دهد. **Microsoft Edge** صداهای فارسی طبیعی و رایگان «فرید» و «دلارا» دارد و همین افزونه در Edge هم نصب می‌شود (`edge://extensions` ← Load unpacked).
- از منوی افزونه ← «خواندن» می‌توانی صدا را انتخاب و امتحان کنی.

### دیکشنری از کجا معنی می‌آورد؟

معنی فارسی از [MyMemory](https://mymemory.translated.net) و تعریف انگلیسی و تلفظ از [Free Dictionary API](https://dictionaryapi.dev) — هر دو رایگان و بدون کلید. فقط همان کلمه‌ای که رویش کلیک کردی فرستاده می‌شود.

### مصرف Claude از کجا می‌آید؟

همان عددهای صفحه‌ی **Settings ← Usage** خود Claude است: افزونه با همان ورودِ خودت در claude.ai از آدرس داخلی `claude.ai/api/organizations/…/usage` می‌خواند؛ چیزی به جای دیگری فرستاده نمی‌شود. بعد از هر پاسخ (دو بار: ۲ و ۲۰ ثانیه بعد، چون Claude مصرف را با کمی تأخیر ثبت می‌کند)، وقتی به تب برمی‌گردی و هر ۵ دقیقه به‌روز می‌شود و بین تب‌ها مشترک است. این آدرس رسمی و مستند نیست؛ اگر Claude عوضش کند، کارت مصرف خبر می‌دهد و لینک صفحه‌ی Usage خود Claude را نشان می‌دهد. خاموش کردن: منوی افزونه ← «مطالعه».

### پومودورو وقتی تب بسته است

زمان‌سنج در پس‌زمینه‌ی افزونه اجرا می‌شود؛ اگر تب Claude بسته یا در پس‌زمینه باشد، اعلان سیستم می‌آید و وقتی برگردی وضعیت درست نشان داده می‌شود.

### نوار ابزار جمع‌شونده

دکمه‌ی بالای نوار ابزار (⤡) آن را به یک دایره‌ی کوچک بالا سمت راست صفحه تبدیل می‌کند. دایره را می‌شود با موس هر جا کشید (جایش یادش می‌ماند) و با یک کلیک نوار ابزار دوباره باز می‌شود. روی پنجره‌ی باریک (مثلاً وقتی کروم را کوچک می‌کنی) نوار ابزار خودش به همین دایره تبدیل می‌شود تا روی متن نیفتد و با بزرگ شدن پنجره برمی‌گردد.

### Claude Code (claude.ai/code) و صفحه‌های دیگر

افزونه پیام‌ها را اول با کلاس‌های خود Claude پیدا می‌کند و اگر نبود (مثل صفحه‌ی Claude Code یا بعد از تغییر طراحی سایت)، متن‌های Markdown/پاسخ‌ها را خودش تشخیص می‌دهد. تم‌ها هم به اسم متغیرهای CSS خود Claude وابسته نیستند: رنگ‌های صفحه همان لحظه شناسایی و عوض می‌شوند و اگر لازم باشد پس‌زمینه‌ی بخش خواندن مستقیم رنگ می‌شود.

بعد از اعمال تم، افزونه کنتراست واقعی متن‌ها را می‌سنجد: اگر جایی (مثلاً بلوک کدی که رنگ‌هایش برای حالت تیره‌ی Claude ثابت شده) روی تم انتخابی ناخوانا شده باشد، پس‌زمینه‌ی آن بلوک یا رنگ آن متن را خودکار خوانا می‌کند. متن فارسی‌ای که Claude داخل بلوک کد بنویسد هم راست‌به‌چپ و با فونت فارسی نمایش داده می‌شود (کد واقعی چپ‌به‌راست می‌ماند). آیکن‌ها و شکلک‌های خود Claude فونت خودشان را نگه می‌دارند تا مستطیل خالی نشوند.

### Notion AI

افزونه روی چت Notion AI هم کار می‌کند، هم پنل گوشه‌ی پایین صفحه‌ها و هم صفحه‌ی کامل Notion AI. همه‌ی ابزارها (فونت، راست‌چین، هایلایت، یادداشت، فهرست، ترجمه، تم و…) فقط روی خود چت اعمال می‌شوند. **متن صفحه‌های Notion دست نمی‌خورد**: صفحه‌ها قابل ویرایش‌اند و افزونه هیچ چیزی در آن‌ها نمی‌نویسد.

- چت از روی ساختارش پیدا می‌شود: کادر «Ask AI…»، فهرست پیام‌های بالای آن، حباب‌های سؤال تو در سمت راست و پاسخ‌ها کنارشان. اگر Notion ظاهرش را عوض کند و چیزی پیدا نشد، «گزارش عیب‌یابی» را با چت باز بگیر و بفرست.
- حافظه‌ی هر چت جداست. اگر آدرس صفحه شناسه‌ی چت را داشته باشد با همان ذخیره می‌شود، وگرنه با اولین سؤالی که در آن چت پرسیده‌ای. در کتابخانه با نام «Notion AI: …» دیده می‌شود.
- تم فقط پنل چت را رنگ می‌کند و حالت روشن/تیره‌ی خود Notion عوض نمی‌شود.
- نوار ابزار روی Notion اول به شکل دایره‌ی کوچک سمت چپ است تا روی پنل چت نیفتد. روی دایره بزن تا باز شود.
- متن پاسخ‌های Notion AI با سیستم ویرایش خود Notion ساخته می‌شود؛ افزونه داخل آن هیچ تغییری نمی‌دهد و هایلایت‌ها را **روی** متن نقاشی می‌کند (CSS Custom Highlight API). رنگ‌ها، زیرخط و خط‌خورده دقیق دیده می‌شوند؛ پررنگ با سایه‌ی نازک، کج به‌صورت زیرخط‌چین، کادر به‌صورت خط بالا و پایین و یادداشت با زیرخط نقطه‌چین نارنجی نشان داده می‌شود.

اگر Notion ظاهرش را عوض کرد و چیزی کار نکرد، ساختار چت (بدون نیاز به افزونه) این‌طور گرفته می‌شود: چت را باز کن، F12 ← Console و این را اجرا کن؛ فایل `notion-chat-structure.html` دانلود می‌شود. `dev/notion-dump-to-mock.mjs` آن را به یک صفحه‌ی آزمایشی بی‌نام تبدیل می‌کند (متن‌ها با حروف بی‌معنی عوض می‌شوند).

```js
(() => {
  const root = document.querySelector('[data-agent-chat-survey-shortcut-scope]') || document.querySelector('[data-csr-chatroot]') || document.body;
  const props = ['display', 'position', 'overflow-y', 'background-color', 'border-radius', 'border-top-width', 'direction', 'text-align', 'color', 'font-family', 'user-select'];
  const clone = root.cloneNode(true);
  const src = [root, ...root.querySelectorAll('*')];
  const dst = [clone, ...clone.querySelectorAll('*')];
  src.forEach((el, i) => {
    const cs = getComputedStyle(el);
    const r = el.getBoundingClientRect();
    dst[i].setAttribute('data-cs', props.map((p) => p + ':' + cs.getPropertyValue(p)).join(';') + `;box:${Math.round(r.left)},${Math.round(r.top)},${Math.round(r.width)}x${Math.round(r.height)}`);
  });
  const a = document.createElement('a');
  a.href = URL.createObjectURL(new Blob([clone.outerHTML], { type: 'text/html' }));
  a.download = 'notion-chat-structure.html';
  a.click();
})();
```

### گزارش عیب‌یابی

اگر روی صفحه‌ای چیزی درست کار نکرد: منوی افزونه ← «ابزارها» ← «کپی گزارش عیب‌یابی». متن کپی‌شده فقط ساختار صفحه (اسم تگ‌ها، کلاس‌ها و رنگ‌ها) را دارد، نه متن پیام‌هایت؛ آن را برای سازنده بفرست.

## به‌روزرسانی

افزونه هر ۶ ساعت (و با دکمه‌ی «بررسی به‌روزرسانی» در منو ← ابزارها) گیت‌هاب را نگاه می‌کند. اگر نسخه‌ی تازه‌ای باشد، روی آیکون افزونه **NEW** می‌آید و بالای منو دکمه‌ی «دانلود نسخه‌ی جدید» و تغییرات را نشان می‌دهد. بعد از جایگزین کردن فایل‌ها، «بارگذاری دوباره‌ی افزونه» را بزن؛ تب‌های Claude خودشان تازه می‌شوند.

> افزونه‌ای که از پوشه نصب شده (Load unpacked) نمی‌تواند فایل‌های خودش را عوض کند؛ این محدودیت امنیتی خود کروم است.

- **بدون هیچ دانلودی:** مخزن را یک بار با [GitHub Desktop](https://desktop.github.com) روی کامپیوترت Clone کن و `claude-reader/extension` همان‌جا را در کروم Load unpacked کن. از آن به بعد هر بار فقط در GitHub Desktop دکمه‌ی **Fetch/Pull** و بعد در منوی افزونه «بارگذاری دوباره‌ی افزونه» را بزن.
- **کاملاً خودکار:** فقط با انتشار در Chrome Web Store (می‌تواند «Unlisted» باشد تا فقط با لینک دیده شود) ممکن است؛ هزینه‌ی یک‌باره‌ی ۵ دلار حساب توسعه‌دهنده و چند روز بررسی اول دارد.

برای سازنده: بعد از هر تغییر، نسخه را در `extension/manifest.json` و `update.json` بالا ببر و `sh dev/package.sh` را اجرا کن تا `dist/khana-extension.zip` ساخته شود.

## حافظه (بعد از برگشتن چیزی پاک نمی‌شود)

همه‌چیز (هایلایت، یادداشت، برچسب، نشانک، طراحی، پیشرفت و آخرین جای خواندن) برای **هر گفتگو جداگانه** با شناسه‌ی آدرس آن (`claude.ai/chat/…`) در حافظه‌ی خود کروم (`chrome.storage.local`) ذخیره می‌شود. وقتی به آن گفتگو برگردی — با رفرش، بستن و بازکردن مرورگر، یا رفتن به گفتگوی دیگر و برگشتن — هایلایت‌ها، یادداشت‌ها، خط‌ها و طراحی‌ها دوباره سر جایشان می‌آیند. تنظیمات (فونت، تم، …) در `chrome.storage.sync` است و با حساب کروم بین دستگاه‌ها همگام می‌شود.
هیچ داده‌ای به هیچ سروری فرستاده نمی‌شود. برای اطمینان، از کتابخانه گاهی «پشتیبان‌گیری (JSON)» بگیر.

کلیدها با کیبورد فارسی هم کار می‌کنند.

## محدودیت‌های فعلی

- طراحی‌های مداد به نزدیک‌ترین حرف زیرشان چسبیده‌اند و با تغییر فونت یا عرض صفحه همراهش جابه‌جا و بزرگ/کوچک می‌شوند؛ اما اگر یک خط بلند روی چند کلمه کشیده باشی و آن کلمه‌ها بعد از بزرگ‌شدن فونت در دو خط بشکنند، خطِ کشیده‌شده خودش نمی‌شکند.
- اگر پاسخی را دوباره تولید (Retry) یا ویرایش کنی و متن عوض شود، هایلایت‌های آن قسمت در پنل با برچسب «در صفحه پیدا نشد» می‌مانند (پاک نمی‌شوند).
- اگر Claude ساختار صفحه‌اش را عوض کند، ممکن است لازم باشد انتخابگرهای `extension/src/content/dom.js` (بخش `SEL`) به‌روز شوند.

## ساختار پروژه

```
extension/              ← همین پوشه را در کروم Load unpacked کن
  manifest.json
  fonts/                ← فونت‌ها (همه OFL)
  src/shared/           ← تنظیمات پیش‌فرض، تم‌ها، ذخیره‌سازی، خروجی Markdown
  src/content/          ← کدی که داخل claude.ai اجرا می‌شود
    dom.js              ← پیدا کردن پیام‌ها و لنگر متن (برای برگرداندن هایلایت‌ها)
    appearance.js       ← فونت، تم، راست‌چین، حفظ آیکن‌های Claude
    annotations.js      ← هایلایت، قالب، یادداشت، نقل‌قول، خط جداکننده
    drawing.js          ← مداد
    notion.js           ← پیدا کردن چت Notion AI (سؤال‌ها و پاسخ‌ها) بدون دست زدن به صفحه‌ها
    theme.js            ← تم‌ها روی هر نسخه‌ای از سایت (شناسایی رنگ‌ها + رنگ‌کردن بخش خواندن + اصلاح کنتراست)
    focus.js / ruler.js ← حالت تمرکز، خط‌کش خواندن
    diag.js             ← گزارش عیب‌یابی (بدون متن پیام‌ها)
    tts.js / dict.js    ← خواندن با صدا، دیکشنری
    toc.js              ← فهرست خودکار و پیشرفت
    study.js            ← زمان مطالعه، پومودورو و پنجره‌ی ترمه
    usage.js            ← مصرف Claude (سهمیه‌ی ۵ ساعته و هفتگی)، به‌روز بعد از هر پاسخ
  src/background.js     ← ساعت پومودورو، اعلان‌ها، درخواست دیکشنری
  src/shared/patterns.js← نقش‌های ایرانی (ترمه، کاشی، خاتم، گلیم، اسلیمی) و شمسه
    ui.js / ui.css      ← نوار کناری، نوار انتخاب، پنل
    main.js             ← راه‌اندازی، دنبال‌کردن تغییرات صفحه، میان‌برها
  src/popup/            ← منوی تنظیمات افزونه
  src/library/          ← کتابخانه‌ی یادداشت‌ها
dev/                    ← تست خودکار، ساخت آیکون و پیش‌نمایش نقش‌ها (لازم برای استفاده نیست)
```

## تست خودکار

```bash
cd dev
npm install
CHROMIUM_PATH=/path/to/chrome npm test
```

تست، افزونه را در کرومیوم باز می‌کند، یک صفحه‌ی شبیه‌سازی‌شده‌ی claude.ai (با React) را جای سایت اصلی می‌گذارد و همه‌ی قابلیت‌ها را امتحان می‌کند؛ عکس‌ها در `dev/out/` ذخیره می‌شوند.
